# 📖 Overview

Enterprise Asset Management System (EAM) is a modern web application designed to manage the complete lifecycle of organizational assets.

The application enables organizations to efficiently manage:

- Asset Inventory
- Asset Categories
- Asset Assignment
- Maintenance Scheduling
- Reports & Analytics
- Administrative Settings
- Authentication
- Enterprise Dashboard

The project follows enterprise software engineering practices including layered architecture, reusable components, repository-service pattern, modular folder organization, and scalable frontend design.

# 🚀 Getting Started

Clone repository

```bash
git clone https://github.com/yourusername/enterprise-asset-management.git
```

Navigate

```bash
cd enterprise-asset-management
```

Install dependencies

```bash
npm install
```

Run

```bash
npm run dev
```

Production Build

```bash
npm run build
```

Preview

```bash
npm run preview
```
